Проведи пользователю тест «ИИ-мастер».

0. Если пользователь просит открыть сохранённый результат («открой мой результат ИИ-мастер»,
   «покажи мой результат теста») — замер не запускай: открой `~/.claude/ii-master-result.html`
   в браузере по умолчанию (`open` / `xdg-open` / `start`). Файла нет — скажи, что сохранённого
   результата на этом компьютере нет, и предложи пройти тест (шаги ниже).

1. Сначала скажи по-русски, в двух-трёх предложениях, что сейчас произойдёт: ты посчитаешь его
   реальные диалоги с Claude Code на этом компьютере и по ним замеришь 11 привычек работы с ИИ по
   шкале из исследования Anthropic; всё считается локально, наружу ничего не отправляется, в
   результат попадают только числа и имя, если человек сам захочет указать его для страницы.

2. Запусти подсчёт диалогов (Windows: `python` вместо `python3`):

   `python3 "${CLAUDE_PLUGIN_ROOT}/skills/ii-master/measure/extract.py" && python3 "${CLAUDE_PLUGIN_ROOT}/skills/ii-master/measure/clean.py"`

   В выводе будет строка `SUMMARY {...}` с полями `multiturn` (сколько многоходовых диалогов) и
   `route`.

3. Роутинг:
   - `route: "auto"` (многоходовых 5 и больше) — скажи, сколько диалогов нашлось, и проведи
     авто-замер по скиллу `ii-master` (шаги с разметки, шаг 0 уже сделан).
   - `route: "quiz"`, python не нашёлся или скрипт упал — скажи честно, что реальной истории пока
     мало или посчитать её не вышло, поэтому будет экспресс-вариант: три коротких задания на 5–10
     минут, результат по той же шкале. Проведи его по скиллу `quiz`.

Правила: только русский язык наружу, без эмодзи в служебном тексте, не обещай ничего сверх того,
что делают скиллы. Если пользователь передумал — остановись без уговоров.
