# ИИ-мастер — тест навыков работы с ИИ для Claude Code

Плагин Claude Code, который замеряет, как вы на самом деле работаете с ИИ, — по шкале из
исследования Anthropic (11 привычек, от постановки цели до проверки фактов). Средний результат в
исследовании — 3–4 привычки на диалог; тест покажет ваш балл, сильные стороны, зону роста и фишки
Claude Code, которые вы пока не трогали. В конце — страница результата, карточка для сторис и,
по желанию, персональный тренер прямо в вашем Claude.

Тест бесплатный.

## Установка

В Claude Code выполните две команды:

```
/plugin marketplace add mariafonina/ii-master
/plugin install ii-master@mariafonina-ii-master
```

Затем напишите в чат:

```
пройди тест ИИ-мастер
```

или вызовите `/ii-master`.

## Как это работает

- Если у вас на компьютере есть 5 и больше многоходовых диалогов с Claude Code, тест замерит
  вашу реальную историю: скрипты соберут ваши реплики, а модель вручную разметит до 80 последних
  многоходовых диалогов по 11 привычкам — без ключевых слов, по смыслу.
- Если истории мало, будет экспресс-тест: три коротких задания на 5–10 минут, балл по той же
  шкале с пометкой «экспресс-тест».
- Результат: страница с баллом «X из 11» и полосами против базы, список фишек Claude Code,
  которые вы не используете, карточка 1080×1920 и 1080×1080 для сторис и чатов.
- Команда «перемерь» через месяц покажет динамику «было — стало».

## Приватность

Всё считается локально на вашем компьютере. Скрипты замера читают логи Claude Code из
`~/.claude/projects`, никуда ничего не отправляют и не ходят в сеть; страница и карточка —
локальные файлы. В результат попадают только нули и единицы разметки, проценты и имя, если вы
сами укажете его для страницы: тексты ваших диалогов, пути и секреты в него не входят.
Промежуточные файлы замера лежат в `~/.claude/ii-master-work` — их можно посмотреть (там видно,
что именно считалось) и удалить после теста, для перемера папка пересоберётся. Код скриптов
открыт — папка `plugins/ii-master/skills/ii-master/measure/`.

Персональный тренер включается только после вашего явного согласия и хранит профиль в
`~/.claude/ii-master-profile.json` у вас на компьютере. В своих подсказках тренер ничего не
продаёт.

## Что внутри

| Часть | Что делает |
|---|---|
| `/ii-master` | роутер: считает ваши диалоги и выбирает авто-замер или экспресс-тест |
| скилл `ii-master` | авто-замер по реальной истории, страница результата, разбор |
| скилл `quiz` | экспресс-замер: три задания, балл по той же шкале |
| скилл `share-card` | карточка с баллом: сторис 1080×1920 и квадрат 1080×1080 |
| скилл `ii-trener` | персональный тренер по вашему профилю, по согласию |
